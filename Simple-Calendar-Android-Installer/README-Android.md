# 📱 Install Simple Calendar on Android

**[⬇️ Tap to download the app (Simple-Calendar-v42.apk)](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Android-Installer/Simple-Calendar-v42.apk)**

1. **Tidy up (if updating):** open **Files > Downloads** and delete old Simple Calendar `.apk` files.
2. **Download:** tap the link above. If Chrome warns you, tap **Download anyway**.
3. **Open it:** tap **Open** when it finishes, or find **Simple-Calendar-v42.apk** in **Files > Downloads**.
4. **Allow it:** if asked, tap **Settings**, turn on **Allow from this source**, then go back.
5. **Install:** tap **Install** (or **Update**). If Play Protect warns you, tap **More details**, then **Install anyway**.
6. **Allow alarms:** when the app opens, say **Allow** to notifications, alarms and battery.

## ✅ Important for alarms
Go to **Settings > Apps > Simple Calendar > Battery** and choose **Unrestricted**. On Android 14 or newer, also turn on **Allow full-screen alarms** if you see it.

## 🧪 Quick test
Create an event 2 minutes from now, close the app and lock your phone. The alarm should ring.

## ⬆️ Updating
The app checks for updates regularly and shows **Update available** with what's new. You can also tap **Options → Check for updates**.

Tap **Download now**. The app downloads the update, checks it, and opens Android's installer. Tap **Update**. The first time, Android asks you to allow Simple Calendar to install apps: turn on **Allow from this source** and go back. Your events, marks and settings are kept.

On v41 or older, install v42 by hand once using the link above. Don't uninstall first.

## ❓ Help
- **No sound:** check the alarm volume and that battery is set to **Unrestricted**.
- **"App not installed":** make sure you opened the newest file (**Simple-Calendar-v42.apk**), not an old one from Downloads.
