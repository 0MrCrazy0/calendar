# 📱 Install Simple Calendar on Android

**[⬇️ Tap to download the app (.apk)](https://github.com/0MrCrazy0/calendar/raw/refs/heads/main/Simple-Calendar-Android-Installer/Simple-Calendar-Android-Installer.apk)**

1. **Download:** tap the link above. If Chrome warns you, tap **Download anyway**.
2. **Open it:** tap **Open** when it finishes, or find it in **Files > Downloads**.
3. **Allow it:** if asked, tap **Settings**, turn on **Allow from this source**, then go back.
4. **Install:** tap **Install**. If Play Protect warns you, tap **More details**, then **Install anyway**.
5. **Allow alarms:** when the app opens, say **Allow** to notifications, alarms and battery.

## ✅ Important for alarms
Go to **Settings > Apps > Simple Calendar > Battery** and choose **Unrestricted**. On Android 14 or newer, also turn on **Allow full-screen alarms** if you see it.

## 🧪 Quick test
Create an event 2 minutes from now, close the app and lock your phone. The alarm should ring.

## ❓ Help
- **No sound:** check the alarm volume and that battery is set to **Unrestricted**.
- **"App not installed":** uninstall the old version, then try again.
- **Updating:** install the new .apk over the old one. Your events stay.
